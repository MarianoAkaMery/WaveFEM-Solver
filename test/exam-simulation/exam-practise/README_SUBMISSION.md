# Practical submission - exam simulation

This folder contains only the practical/code material requested by the exam trace.

## Covered practical points

- Exercise 1.5: deal.II finite element solver for the elliptic problem with Dirichlet-Neumann domain decomposition and relaxation.
- Exercise 1.6: run 15 Dirichlet-Neumann iterations for `lambda = 1.0` and `lambda = 0.25`, output final solutions and line profile on `y = 0.5`.
- Exercise 2.5: deal.II unsteady Stokes solver with Taylor-Hood `P2/P1`.
- Exercise 2.6: output final-time solution, velocity magnitude profile along `y = x`, and velocity magnitude over time at `(1.25,-0.4)^T`.

The theory points are not duplicated here; they belong in `../exam-theory/`.

## Files

- `CMakeLists.txt`: builds both executables.
- `src/Exercise1PoissonDD.*`: subdomain solver for Exercise 1.
- `src/exercise1_domain_decomposition.cpp`: runs Exercise 1 for both relaxation values.
- `src/Exercise2UnsteadyStokes.*`: unsteady Stokes solver for Exercise 2.
- `src/exercise2_unsteady_stokes.cpp`: runs Exercise 2 with `mu = 1`, `T = 1`, `dt = 0.02`.
- `mesh/*.msh`: mesh files downloaded from the course GitHub repositories.
- `scripts/plot_csv_profiles.py`: creates PNG plots from generated CSV profiles using `matplotlib`.

## Build and run

From `exam-practise/`:

```bash
ls -lh mesh/*.msh

rm -rf build
cmake -S . -B build
cmake --build build -j$(nproc)

cd build
./exercise1_domain_decomposition
./exercise2_unsteady_stokes

cd ..
python -m pip install --user --upgrade "numpy>=1.23,<2" matplotlib
python scripts/plot_csv_profiles.py output
find output -maxdepth 2 -type f
```

If your environment uses modules, load deal.II before the CMake step.

Do not run `cmake ..` from inside `exam-practise/`. The command `cmake ..` is valid only after entering `exam-practise/build/`.

## Lines to write on the paper

Exercise 1.5/1.6:

I implemented a finite element solver for `-div(grad u) + u = 1` on `(0,3)x(0,1)`, split into `Omega_1=(0,1)x(0,1)` and `Omega_2=(1,3)x(0,1)`. I used linear finite elements and a Dirichlet-Neumann iteration on the interface `x=1`. The interface value is updated with relaxation `g^{k+1}=(1-lambda)g^k+lambda u_2^{k+1}|_Gamma`. I ran 15 iterations for `lambda=1.0` and `lambda=0.25`. I generated final solution plots and the line profile on `y=0.5`.

Exercise 2.5/2.6:

I implemented the unsteady Stokes problem with Taylor-Hood `P2/P1`, viscosity `mu=1`, final time `T=1`, and backward Euler with `dt=0.02`. I imposed zero velocity on `Gamma_2 union Gamma_3`. The traction condition `mu partial_n u - p n = -p_0 n` is imposed naturally on `Gamma_0 union Gamma_1`, with `p_0=1` on `Gamma_0` and `p_0=2` on `Gamma_1`. I generated final-time output, the velocity magnitude profile along `y=x`, and the time trace at `(1.25,-0.4)^T`.

## Manual risks to check

1. Mesh paths: run executables from `exam-practise/build/`, because the code reads `../mesh/*.msh`.
2. Boundary IDs: Exercise 1 uses interface IDs `1` on `Omega_1` and `0` on `Omega_2`; Exercise 2 uses `Gamma_D = 2,3` and `Gamma_N = 0,1`.
3. Neumann signs: Exercise 2 uses the natural RHS `int_{Gamma_N} -p_0 n dot v ds`; Exercise 1 uses flux continuity across the interface.
