# Project Resources

This folder keeps non-source project material together, so the repository root
stays focused on the solver code and the run commands.

Contents:

- `projects.pdf`: official Project 2 assignment.
- `Laboratory Lectures/`: course laboratory PDFs and reference source code.
- `project-intuition-guide/`: beginner-friendly guide for the wave equation
  project.
- `report-assets/`: selected images and small files for the final report or
  presentation.
