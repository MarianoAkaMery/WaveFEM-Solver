- Exercise 2: unsteady Stokes, Taylor-Hood finite elements, backward Euler in time.

- `CMakeLists.txt`: builds both executables.

- `src/exercise1_domain_decomposition.cpp`: runs lambda = 1.0 and lambda = 0.25 for 15 iterations.

## Build and run

From this folder:

```bash
gmsh -2 mesh/mesh-problem-0.geo
gmsh -2 mesh/mesh-problem-1.geo
gmsh -2 mesh/mesh-pipe.geo

cmake -S . -B build
cmake --build build

cd build
./exercise1_domain_decomposition
./exercise2_unsteady_stokes

python ../scripts/plot_csv_profiles.py output
```

If the machine requires MPI launchers, use one process for the CSV post-processing:

```bash
mpirun -np 1 ./exercise2_unsteady_stokes
```

## Lines to write on the paper

Exercise 1.5/1.6:

I implemented a finite element solver for
\(-\mathrm{div}(\nabla u)+u=1\) on \((0,3)\times(0,1)\), split into
\(\Omega_1=(0,1)\times(0,1)\) and \(\Omega_2=(1,3)\times(0,1)\).
I used linear simplex finite elements and a Dirichlet-Neumann iteration on the
interface \(x=1\). The interface value is updated with relaxation
\(g^{k+1}=(1-\lambda)g^k+\lambda u_2^{k+1}|_\Gamma\). I ran 15 iterations for
\(\lambda=1.0\) and \(\lambda=0.25\). The final solution plots are in
`exercise1_solution_lambda_1p00_final.png` and
`exercise1_solution_lambda_0p25_final.png`; the line profile on \(y=0.5\) is in
`exercise1_line_y_0p5.png`.

Exercise 2.5/2.6:

I implemented the unsteady Stokes problem with Taylor-Hood \(P_2/P_1\) finite
elements, viscosity \(\mu=1\), final time \(T=1\), and backward Euler time
stepping with \(\Delta t=0.02\). Zero velocity is imposed on
\(\Gamma_2\cup\Gamma_3\). The traction boundary condition
\(\mu\partial_n u-pn=-p_0n\) is imposed naturally on \(\Gamma_0\cup\Gamma_1\),
with \(p_0=1\) on \(\Gamma_0\) and \(p_0=2\) on \(\Gamma_1\). The final solution
plot is in `exercise2_solution_final.png`; the velocity magnitude profile on
\(y=x\) is in `exercise2_velocity_magnitude_line_y_eq_x_final.png`; the time
trace at \((1.25,-0.4)^T\) is in
`exercise2_velocity_magnitude_probe_time.png`.

## Manual risks to check

1. Boundary IDs: Exercise 1 uses interface IDs 1 on Omega_1 and 0 on Omega_2;
   Exercise 2 uses Gamma_D = 2,3 and Gamma_N = 0,1.
2. Neumann sign: Exercise 2 uses RHS \(\int_{\Gamma_N}-p_0 n\cdot v\,ds\).
3. Exercise 1 flux sign: the Dirichlet-Neumann code uses flux continuity across
   the interface; if the plot looks wrong, check the sign in
   `apply_interface_neumann`.
